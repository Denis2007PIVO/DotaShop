# 🎮 Dota Market — Маркетплейс предметов Dota 2

Учебный проект, объединяющий лабораторные работы №4–7. Представляет собой полноценный веб-маркетплейс с авторизацией, корзиной, балансом, историей покупок и REST API.

## 🚀 Быстрый старт (Принцип «Включил и забыл»)

Проект полностью автоматизирован. Зависимости устанавливаются один раз, после чего для запуска с нуля достаточно одной команды в терминале (находясь в папке `dota_market`):

```bash
pip install -r requirements.txt
python run.py
```

Скрипт автоматически:

- Проверит наличие базы данных.
- Применит миграции (Alembic).
- Заполнит базу тестовыми данными (Seed), если она пуста.
- Запустит веб-сервер Uvicorn.

После запуска откройте в браузере: http://127.0.0.1:8000

Тестовые аккаунты:

- Логин: `alice`, Пароль: `password123` (Баланс: 10 000$)
- Логин: `bob`, Пароль: `password456` (Баланс: 500$)

Настройки можно переопределить через `.env` (пример — в `.env.example`). Без `.env` приложение использует SQLite по умолчанию.

## 📚 Реализованные лабораторные работы

### 🔹 Лабораторная 4: Разработка базы данных (DB-First)

- **Инструменты:** SQLAlchemy 2.0, Alembic.
- **Реализация:** Спроектирована реляционная база данных (пользователи, предметы, корзина, заказы, позиции заказов). Применен принцип DB-First (схема описана декларативно, миграции генерируются автоматически).
- **Файлы:** `app/models/`, `alembic/versions/`

### 🔹 Лабораторная 5: Паттерны проектирования + FastAPI + UI

**Паттерны (GoF и Фаулера):**

- **Repository** (`app/repositories/`) — изоляция работы с БД.
- **Service Layer** (`app/services/market_service.py`) — вынос бизнес-логики (покупка, списание баланса) из роутеров.
- **Dependency Injection** — внедрение зависимостей через `Depends` в FastAPI.
- **Bootstrap / Application Factory** — файл `run.py` для инициализации приложения.
- **Единая точка входа:** `main.py`.

**UI:** Jinja2-шаблоны в `app/templates/`, CSS в `app/static/`.

**Функционал:** Логин/регистрация, пополнение баланса, корзина, фильтры (поиск, редкость, сортировка по цене), история покупок.

### 🔹 Лабораторная 6: Unit-тестирование ПО

- **Инструменты:** Pytest, httpx.
- **Реализация:** Покрыты тестами ключевые сценарии (добавление в корзину, успешная покупка, пограничное условие — нехватка средств).
- **Файлы:** `tests/test_market.py`, `conftest.py`.
- **Запуск тестов:** `pytest`

### 🔹 Лабораторная 7: Документирование ПО (OpenAPI)

- **Инструменты:** FastAPI, Pydantic.
- **Реализация:** Спроектирован REST API для интеграции с другими программами (`/api/items`). Добавлены Pydantic-схемы для валидации. FastAPI автоматически сгенерировал интерактивную документацию Swagger UI.
- **Ссылка на документацию:** http://127.0.0.1:8000/docs

## 🛠 Технологический стек

- **Язык:** Python 3.13
- **Веб-фреймворк:** FastAPI
- **База данных:** SQLite (SQLAlchemy ORM)
- **Миграции:** Alembic
- **Шаблонизатор:** Jinja2
- **Тестирование:** Pytest
- **Валидация данных:** Pydantic
